# HRUM capstone deck

12 slides in English for the course submission and the LinkedIn post. The editable original is a claude.ai Slides
artifact; this folder keeps its source so the deck is versioned with the project.

| File | What |
|---|---|
| `deck.json` | Slide order, sections (outline) and fonts (Space Grotesk, Inter) |
| `slides/<id>.html` | One slide each, in deck order: cover, problem, what, architecture, trust, loop, evals, gate, caught, observability, app, lessons. Speaker notes are in each slide's `<aside>` |
| `assets/app_chat.png`, `assets/app_sql_explorer.png` | The two app screenshots on the `app` slide (referenced there by their uploaded asset ids `/_blob/c2b8…` and `/_blob/4768…`) |
| `HRUM_deck.pdf`, `HRUM_deck.pptx` | Exports from the artifact (Share › Export), added by hand |

Before publishing: replace `[Your name]` (cover) and `[repository link]` (lessons).

Every number on the slides comes from `docs/progress_report.md` and `evals/reports/`.
