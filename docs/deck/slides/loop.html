The agent loop

From question to a checked answer

1 · Plan

Qwen picks tools within a step budget

2 · Tools

Each result becomes evidence E1, E2…

3 · Finalize

JSON answer, each claim cites evidence

4 · Ground

Numbers checked; repair or abstain

5 · Show

Answer, chart, caveats, SQL

First run on the real model

“Berapa total kompensasi FY2026 dan headcount-nya?” → query_metric → “$7,523,952,094.89 with headcount 42,925”, both claims cite E1 · grounding ok, no repair · 3 LLM calls · 3.9 s

The loop is adapted from the course’s agentic RAG lab. Budgets cap steps, tool calls and seconds. Tools tolerate small-model mistakes, such as a list sent as a string. If the model stops without calling any tool, the agent searches the docs itself, a safety net added after the eval found models skipping retrieval.
