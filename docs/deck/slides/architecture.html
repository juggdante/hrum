Architecture

Everything runs on one GPU PC

Governed data

DuckDB + dbt marts, 16 metrics in one semantic layer

HR knowledge

RAG: BM25 + multilingual e5, fused with RRF

Attrition model

XGBoost + SHAP, published only as aggregates

Agent: Qwen3.5-4B on vLLM (RTX 4090, 24 GB)

Tool calling with step and time budgets · SQL guard · numeric grounding with one repair round · abstain when unsure

Streamlit app

Chat with charts, question bank, SQL Explorer

MCP gateway

JWT roles, tool pinning, audit log

Langfuse

Self-hosted traces, names masked

Nothing leaves the building: the model is served by vLLM on a local RTX 4090, the warehouse is a DuckDB file, and the tracing stack is self-hosted with Docker. Three sources feed the agent: the governed semantic layer for numbers, a hybrid retriever over HR documentation for definitions and policy, and an attrition model whose output is aggregated before the agent can see it. The same tools are exposed to the Streamlit app and, through an MCP gateway with role-scoped tokens, to any MCP client.
