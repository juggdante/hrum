The app

What the CHRO sees

Chat. The answer, a chart drawn from the cited rows, caveats, and the SQL behind it.

SQL Explorer (analysts). Row-level reads; SELECT * is rewritten so person keys never show.

Also: a question bank with the 39 verified questions (one click to ask) and a dataset guide built from live warehouse statistics.

Four pages in one Streamlit app. Charts are chosen by code from the shape of the evidence: a single number becomes KPI tiles, a year series a line, one category a sorted bar, two categories a heatmap. The model never draws a chart, so a chart cannot disagree with the grounded text. The SQL Explorer appears only for the analyst role.
