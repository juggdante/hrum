The problem

A CHRO asks a follow-up question. The dashboard has no answer, and a chatbot makes one up.

Dashboards are fixed

They answer the questions someone planned for. “And per department, since 2020?” means a new ticket.

LLMs invent numbers

A fluent answer with a wrong total is worse than no answer for a decision about pay.

HR data is personal

Salaries and names must not leak to a cloud API, a log file or a curious prompt.

Three constraints shaped every design decision: answers must be flexible like a conversation, exact like a report, and private like an HR system.
