## EDA results (2026-11-11, file `Employee_Compensation_20261022.csv`, 1,180,053 rows)
| Check | Result | Decision |
|---|---|---|
| `Employee Name` | Real names, 100% populated, 126,467 distinct; same name + job + dept collides 1,274 times | PII. Hashed to `employee_key` in staging, never reaches marts as text. Not a reliable cross-year person key |
| Year Type | Fiscal 590,892 rows, Calendar 589,161 rows, both FY/CY 2013–2026. They are two views of the SAME pay, not extra people | Marts use **Fiscal only** (FY2026 complete; CY2026 is partial). Never sum across Year Types |
| Totals reconcile | `Total Salary`, `Total Benefits`, `Total Compensation` match their components (0 rows off by > $1) | Use source totals |
| Negatives | 264 fiscal rows with Total Compensation < 0 (adjustments/refunds) | Kept, flagged `is_adjustment` |
| Hours / Employment Type | NULL for all of FY2013–FY2016; populated from FY2017 | Hours-based metrics (FTE, hourly) only FY2017+; agent states this caveat |
| Hours distribution (fiscal) | p50 2,080 (full-time year), p25 1,205, p99 3,344 | `is_full_time` = hours >= 1,820 (35 h/week) |
| Small records | ~550–2,300 rows/yr with Total Compensation < $1,000 | Kept; `headcount` counts rows with Total Salary > 0 |
| Employment Type values | Permanent Civil Service, Temporary Exempt, Permanent Exempt, Other, Temporary Provisional, Temporary Civil Service | Dimension as-is |
| Cardinality | 127 departments, 60 job families, 1,426 jobs | `dim_department`, `dim_job` |
| Missing department | 2 FY2017 rows (General City Responsibilities) with NULL department | Staging maps to `UNK` / "Unknown (not reported)" |
| Amount format | Strings with thousands separators (`"79,185.04"`) | Parsed in staging with `replace(',', '')` |

## Synthetic HRIS layer — `raw.synthetic_hris` → `stg.stg_synthetic__hris` (is_synthetic = true)
Generated by `ingestion/synthetic/generate.py` (seed 42). Population = REAL FY2026 paid records, one row per
`employee_key` (40,344 people). Every field below is SYNTHETIC. Never present output on them as real insight.

| Column | How it is generated |
|---|---|
| hire_date / tenure | Gamma tenure: permanent mean ≈ 9 y, temporary ≈ 1.8 y |
| age_band | 22 + tenure + N(10, 6), banded `<25 … 55+` |
| gender | Bernoulli with a per-job-family female share (e.g. Nursing 0.85, Fire 0.15, default 0.45) |
| level | Salary quintile within job family → L1 (low) … L5 (high) |
| performance_rating | 1–5 with p = .05/.15/.50/.22/.08 |
| location | Uniform over 7 SF sites |
| termination_date / reason | Logistic rule (log-odds): −2.6 base, +0.8 compa < 0.9, +0.9 rating ≤ 2, −0.5 rating 5, +0.9 tenure < 2 y, −0.6 tenure > 15 y, +0.5 overtime/salary > 0.25, +0.7 temporary. FY2026 turnover ≈ 14.6% |

## Marts (schema `mart`, the only schema the agent can read)
| Table | Grain | Real / synthetic |
|---|---|---|
| `fct_compensation` | fiscal-year pay record | REAL |
| `dim_department`, `dim_job` | department / job code | REAL |
| `fct_employee_snapshot` | employee in FY2026 | MIXED — pay real, HRIS synthetic (`is_synthetic = true`) |
| `ml_attrition_risk_segment` | (segment_type, segment), ≥ 5 employees | SYNTHETIC — written by `ml/attrition/score.py`, not dbt |
| `ml_attrition_drivers` | model feature | SYNTHETIC — global mean \|SHAP\| + test metrics |

Attrition model (`ml/registry/attrition/model_card.json`): XGBoost vs logistic-regression baseline, 80/20 stratified
split, deterministic (fixed seed + fixed row order). Test (2026-11-11): ROC-AUC 0.722 vs 0.694, top-decile lift 2.85×. Top drivers recovered = the generator rules
(tenure, performance, compa-ratio, temporary, overtime), which is the expected sanity check on synthetic labels.
Gender is excluded from features; predicted risk by gender F 0.148 vs M 0.144.

Metric definitions: `warehouse/semantic/metrics.yaml` (one definition per metric).
